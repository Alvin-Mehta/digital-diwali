# Design System Specification

## 1. Layout & Breakpoints

- **Mobile:** `< 768px` (Single column, horizontal cracker selector or bottom drawer, full-screen stage).
- **Tablet:** `768px - 1024px` (Balanced two-column, 35% menu / 65% stage).
- **Desktop:** `> 1024px` (Standard two-column, 30% menu / 70% stage, max container width 1440px).

---

## 2. Elevation & Shadows

- `shadow-sm`: `0 1px 2px 0 rgba(0, 0, 0, 0.25)`
- `shadow-md`: `0 4px 6px -1px rgba(0, 0, 0, 0.3), 0 2px 4px -2px rgba(0, 0, 0, 0.2)`
- `shadow-festive`: `0 0 25px rgba(245, 158, 11, 0.25)` (Golden ambient glow)
- `shadow-burst`: `0 0 45px rgba(255, 107, 0, 0.45)` (Explosion flash bloom)

---

## 3. Border Radiuses

- `radius-sm`: `6px` (Badges, tags)
- `radius-md`: `12px` (Buttons, inputs, icon containers)
- `radius-lg`: `18px` (Cracker cards, participant avatars)
- `radius-xl`: `24px` (Modals, stage container)
- `radius-full`: `9999px` (Pills, circular action icons)

---

## 4. Spacing Scale

Based on an 8-point grid:
- `space-1`: `4px`
- `space-2`: `8px`
- `space-3`: `12px`
- `space-4`: `16px`
- `space-6`: `24px`
- `space-8`: `32px`
- `space-12`: `48px`
- `space-16`: `64px`
