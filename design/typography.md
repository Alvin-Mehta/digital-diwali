# Typography & Type Hierarchy

## 1. Font Selection
- **Display & Festive Headers:** Playfair Display, Cinzel, or serif fallback with letter-spacing for festive, royal grandeur.
- **UI & Body Copy:** Inter, Plus Jakarta Sans, system sans-serif (`system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`) for crisp, legible readability.
- **Numbers & Timers:** Tabular figures (`font-variant-numeric: tabular-nums`) to prevent layout jitter on countdowns.

---

## 2. Typographic Scale

| Token | Size | Line Height | Weight | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `text-display` | 3.5rem (56px) | 1.1 | 800 | Welcome Screen "HAPPY DIWALI" |
| `text-h1` | 2.25rem (36px) | 1.2 | 700 | Primary Modal & Page Headers |
| `text-h2` | 1.5rem (24px) | 1.3 | 600 | Section Headers (Cracker Menu, Stage) |
| `text-h3` | 1.125rem (18px) | 1.4 | 600 | Card Titles & Cracker Names |
| `text-body` | 1rem (16px) | 1.5 | 400 | Primary readable copy & descriptions |
| `text-small` | 0.875rem (14px) | 1.5 | 400 | Subtitles, status badges, secondary info |
| `text-micro` | 0.75rem (12px) | 1.4 | 500 | Tags, keyboard shortcut hints, labels |
